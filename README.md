## Getting Started

[Create a new GitHub Codespace](https://revzilla.atlassian.net/wiki/spaces/TD/pages/5841321990/New+Devs+Setup+Task+List) _or_ use the below steps via the CLI locally assuming you have GitHub CLI installed and authenticated.

```bash
gh cs create
# > Comoto-Tech/dev-hub
# default branch is fine
```

Wait some time for your Codespace to initialize and run setup steps.
